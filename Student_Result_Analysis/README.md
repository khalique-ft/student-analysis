# Student Result Analysis System

A beginner-friendly web application to manage student details, store marks, calculate results, and generate analysis with graphs.

## Features
- Add student details
- Store subject-wise marks in MySQL
- Calculate Total, Average & Grade
- View complete results
- Subject-wise performance graphs (Matplotlib)
- Find class Topper
- Calculate overall Pass Percentage

## Technologies Used
- **Backend**: Python, Flask
- **Database**: MySQL
- **Data Analysis**: Pandas, NumPy
- **Visualization**: Matplotlib
- **Frontend**: HTML5, CSS3
